# Partner Panel UI Inventory

*Date to Go – Platonic Companion Platform*  
*Document Version: 1.0 (Phase 0 Discovery Baseline)*

---

## 1. Discovered Partner Route Tree & Architecture

The Partner Panel is configured in `frontend/src/App.tsx` using `react-router-dom` v6. All partner routes are grouped under `/p/*` and guarded by `<RequireAccess>` with RBAC policies enforced via `@date-to-go/access-policy`.

* **Current Shell/Layout**: `<PartnerLayout />` (`frontend/src/layout/PartnerLayout.tsx`) – Currently a bare `<Outlet />` with no shared navigation, header, or sidepane.
* **Dead / Unused Shell**: `<PartnerShell />` (`frontend/src/components/layout/PartnerShell.tsx`) – Dead code; identical bare `<Outlet />` that is not imported anywhere.
* **Route Loading**: Lazy-loaded using `React.lazy()` wrapped with `<Suspense fallback={<SplashScreen />}>`.
